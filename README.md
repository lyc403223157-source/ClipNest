# ClipNest Native

简体中文 | [English](README_EN.md)

ClipNest Native 是 macOS 原生 AppKit 版本。

当前版本：`0.7.3`。支持 Apple Silicon，最低系统版本为 macOS 13。

仓库同时包含 `cross-platform/` 下的 Windows/Linux Tauri MVP。Windows/Linux 使用 `Alt+V` 打开快速面板，保留 `Ctrl+V` 直接粘贴；三个平台都由 GitHub Actions 原生 runner 构建验证。

## 为什么做 ClipNest

AI 时代，我们经常要在 ChatGPT、绘图工具、代码编辑器、文档和聊天软件之间来回倒腾图片与提示词。同一段 Prompt、参考图、文档链接或常用回复，往往一天要复制很多次，普通剪贴板却只记得“刚刚复制的那一个”。

ClipNest 想解决的就是这件小事：把最近复制的内容和真正高频使用的素材放进一个轻量面板，在当前输入位置附近快速选中并粘贴。平时不需要打开管理界面，也不改变系统原来的直接粘贴；需要整理时，再把内容归档到自己的标签组。

- 最近复制的内容自动收集，本地保存。
- Prompt、图片、链接和常用回复可以归档到自定义标签。
- 快速面板固定五行高度，方向键即可完成选择和粘贴。
- macOS、Windows、Linux 使用各自合适的快捷键，不打断正常粘贴习惯。
- 剪贴板数据只保存在本机，不上传网络。

## 下载与运行

从 GitHub Releases 下载对应系统的安装包：macOS 使用 `ClipNest-0.7.3-macos-arm64.zip`，Windows 使用 `.exe` 安装程序，Ubuntu/Debian Linux 使用 `.deb` 安装包。

macOS 版本解压后可把 `ClipNest.app` 拖入“应用程序”。当前预览版使用本地临时签名，尚未经过 Apple Developer ID 公证；首次运行如果被 Gatekeeper 阻止，可在 Finder 中右键 App 后选择“打开”。

## 当前交互

- 启动后只常驻菜单栏，不主动打开内容管理窗口。
- 复制的文本与图片会自动进入固定的“最近”标签，不限制保存条数。
- 支持截图：按 `Control + Shift + Command + 3` 将全屏截图复制到剪贴板，或按 `Control + Shift + Command + 4` 框选截图；ClipNest 会自动保存并显示缩略图。
- 自定义标签不限制内容条数，可在管理窗口从当前剪贴板添加文本或图片，并可重命名、编辑和删除。
- 在管理窗口选中“最近”中的条目后，点“添加到标签…”可从原生下拉菜单选择已有标签或直接新建标签；归档成功后，该条目会从“最近”移除。
- 管理窗口采用 macOS 系统设置式结构：透明统一标题栏、毛玻璃源列表侧栏、SF Symbols、分组卡片和无边框内容列表。
- 管理窗口默认使用 900 × 620 的舒展尺寸；分组卡片使用系统弱强调底色，内容行采用缩进分隔线。
- `Command + V` 始终保持 macOS 原来的直接粘贴，不再被 ClipNest 接管。
- 在其他应用的输入框中按 `Control + V`，面板优先贴着当前输入框上方弹出；上方空间不足时显示在输入框下方。
- 第一次按 `Control + V` 时，面板顶部会出现一次非阻塞引导；成功粘贴后自动消失。
- 选择条目后恢复原输入框焦点，并把文本或图片粘贴到当前光标或选区。目标 App 本身需要支持粘贴图片。
- 面板使用左右方向键切换分段标签，上下方向键选择内容，Return 粘贴，Esc 关闭。
- 面板内容区始终按 5 行高度展示，超过 5 条时使用 macOS 原生滚动条浏览。
- 每次打开快速面板或管理窗口，都会回到“最近”并选中第一条，不保留上次的标签和条目选择。
- 快速面板使用 AppKit `NSVisualEffectView` 的原生 Popover 毛玻璃材质，并随系统深浅色与桌面背景变化；外框使用 Apple 浮层式连续圆角与柔和阴影，选中条目使用系统强调色。
- 五行内容采用更舒展的系统行距；数字快捷键放在右侧，遵循 macOS 菜单“内容在左、快捷键在右”的信息结构。
- 投影完全交给 macOS WindowServer：快速面板启用原生 `NSPanel.hasShadow`，不再使用自绘 `CALayer` 阴影或额外透明安全区。
- 快捷键说明只在首次引导中出现，不再长期占用面板底部空间；顶部仍保留标签分段控件，兼顾菜单手感与左右键切换标签。
- 多行文本在列表中使用 `↵` 压缩为单行预览，粘贴时仍保留原始换行；窗口阴影使用独立的圆角路径，不再露出矩形底角。
- 未设置自定义名称时，文本按剪贴板原文显示且原样粘贴；图片显示真实像素尺寸，不再自动改成“截图 + 时间”。
- 也可按数字键 1–5 直接选择并粘贴。
- 面板显示时会明确接管键盘选择；点击面板外部会直接关闭，外部点击仍会正常传递给目标 App。
- 确认条目时会把所选内容粘贴回原输入框，`Command + V` 全程保持系统行为。
- 消失规则遵循 macOS 菜单：单击条目或 Return 执行后关闭；Esc、外部点击、切换 App、再次按唤起快捷键时关闭；面板内部操作和短暂焦点切换不会误关。

## 首次使用

`Control + V` 打开面板本身不要求输入监控权限；定位输入框与回填内容需要 macOS 辅助功能权限。App 不会在启动时突然索要权限，第一次按 `Control + V` 时才会给出引导并请求授权。管理窗口可直接打开“系统设置 → 隐私与安全性 → 辅助功能”。如果列表里没有 ClipNest，请点列表底部的“+”，再选择 `ClipNest.app`。建议先将 App 放入“应用程序”文件夹，再进行授权，避免移动 App 后需要重新授权。

所有文本记录与截图都只保存在本机 `~/Library/Application Support/ClipNest`，不会上传网络。删除图片条目或标签时，对应的本地图片文件也会删除。

## 本机构建

当前源码使用 AppKit 与 ApplicationServices，可使用 Xcode 或匹配系统 SDK 的 `swiftc` 构建。交付目录中的 `ClipNest.app` 已使用临时本地签名，最低系统版本为 macOS 13。

仓库根目录提供构建脚本：

```sh
./build.sh
```

构建结果位于 `dist/ClipNest.app`，当前脚本面向 Apple Silicon。

本地预览版必须保留稳定的指定要求进行签名，否则每次替换二进制后，macOS 可能仍显示旧权限开关已打开，但实际拒绝新版的辅助功能权限：

```sh
codesign --force --deep --sign - --requirements '=designated => identifier "com.clipnest.native"' ClipNest.app
```

正式发布时应改用稳定的 Apple Developer ID 签名与公证。
